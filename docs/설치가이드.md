# 설치 가이드

이 저장소에 코드를 올리면(push) GitHub Actions가 Mac 서버에서 자동으로 앱을 빌드합니다.
**Mac이 없어도** 빌드 결과물을 내려받아 설치할 수 있습니다.

## 0. 빌드 결과물 내려받기

1. GitHub 저장소 → **Actions** 탭 → 가장 최근의 초록색 ✓ **Build** 실행을 엽니다.
2. 아래쪽 **Artifacts** 에서 `HWPViewer-builds` 를 내려받아 압축을 풉니다.
   - `HWPViewer-macOS.zip` — Mac용 앱
   - `HWPViewer-unsigned.ipa` — iPhone/iPad용 (서명 전 파일)

---

## 1. Mac에 설치 (무료)

1. `HWPViewer-macOS.zip` 압축을 풀고 `HWPViewer.app` 을 **응용 프로그램** 폴더로 옮깁니다.
2. 처음 실행하면 "확인되지 않은 개발자" 경고가 뜹니다 (Apple 유료 인증서로 서명하지 않았기 때문).
   - **시스템 설정 → 개인정보 보호 및 보안** 맨 아래 **"그래도 열기"** 를 누릅니다.
   - 또는 터미널에서 한 번: `xattr -cr /Applications/HWPViewer.app`
3. `.hwp` 파일을 우클릭 → **다음으로 열기 → HWPViewer** → (항상 이 앱으로 열려면) **정보 가져오기 → 다음으로 열기 → 모두 변경**.

## 2. iPhone / iPad에 설치

### 방법 A — 무료 Apple ID로 사이드로딩 (Windows PC 또는 Mac 필요)

1. PC에 [Sideloadly](https://sideloadly.io) (또는 [AltStore](https://altstore.io))를 설치합니다.
2. iPhone을 USB로 연결 → Sideloadly에 `HWPViewer-unsigned.ipa` 를 끌어다 놓고 Apple ID로 로그인 → **Start**.
3. iPhone에서 **설정 → 개인정보 보호 및 보안 → 개발자 모드** 켜기 (iOS 16 이상, 재시동 필요),
   **설정 → 일반 → VPN 및 기기 관리** 에서 내 Apple ID 인증서를 **신뢰**.
4. 무료 Apple ID 서명은 **7일마다 다시 설치**해야 합니다 (AltStore는 자동 갱신 가능).

### 방법 B — Apple Developer Program (연 $99) + TestFlight

PC 없이 iPad에서 바로 설치하고, 가족·동료에게도 배포(최대 1만 명)할 수 있습니다. 올린 빌드는 90일간 쓸 수 있고, 새로 올리면 계속 이어집니다.
1. [developer.apple.com](https://developer.apple.com/programs/) 가입.
2. App Store Connect에서 앱 등록 (번들 ID: `com.hyroot2.HWPViewer`, 바꾸려면 `Config/Local.xcconfig`).
3. Mac이 있으면 Xcode에서 **Product → Archive → Distribute App → TestFlight**.
   Mac이 없으면 App Store Connect API 키를 저장소 Secrets에 넣어 GitHub Actions로 업로드하도록 워크플로를 추가할 수 있습니다.
4. iPhone에서 **TestFlight** 앱으로 설치.

### 방법 C — Mac + Xcode가 있을 때 (무료, 7일)

유료 계정 없이 무료 Apple ID로 iPhone/iPad에 직접 설치합니다. 처음 한 번 30분~1시간(대부분 Xcode 다운로드 시간)이 걸립니다.

**① Xcode 설치** — Mac의 App Store에서 **Xcode** 검색 → 받기 (용량이 커서 오래 걸립니다). 설치 후 한 번 실행해 약관에 동의하고, 구성 요소 선택 화면에서 **iOS** 를 체크합니다.

**② Homebrew 설치** (이미 있으면 건너뜀) — **터미널** 앱을 열고 붙여 넣기:
```sh
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
```
설치가 끝나면 화면 마지막 "Next steps"에 나오는 두 줄(`echo ... >> ~/.zprofile`, `eval ...`)도 그대로 실행합니다.

**③ 저장소 내려받기와 프로젝트 준비**
```sh
cd ~/Documents
git clone https://github.com/hyroot2-anonymous/Viewer.git
cd Viewer
./scripts/setup-mac.sh
```
스크립트가 XcodeGen 설치, 개인 설정 파일(`Config/Local.xcconfig`) 생성, Xcode 프로젝트 생성을 하고 Xcode를 엽니다.

**④ Xcode에 Apple ID 연결** — Xcode 메뉴 **Xcode → Settings… → Accounts** → 왼쪽 아래 **+** → **Apple ID** → 로그인.

**⑤ 서명 팀 선택** — 왼쪽 파일 목록 맨 위 **HWPViewer**(파란 아이콘) → 가운데 **TARGETS: HWPViewer** → **Signing & Capabilities** 탭 → **Team** 에서 *내 이름 (Personal Team)* 선택.
- "…is not available" 같은 **번들 ID 오류**가 나면: `Config/Local.xcconfig` 를 텍스트 편집기로 열어 `PRODUCT_BUNDLE_IDENTIFIER = com.내영문이름.HWPViewer` 로 바꾸고 `./scripts/setup-mac.sh` 를 다시 실행합니다.
- 스크립트를 다시 실행하면 Team 선택이 초기화됩니다. 매번 고르기 싫으면 **Build Settings** 탭에서 *Development Team* 값(영문·숫자 10자리)을 복사해 `Config/Local.xcconfig` 의 `DEVELOPMENT_TEAM =` 뒤에 붙여 넣으세요.

**⑥ iPad 연결과 준비**
1. iPad를 USB로 Mac에 연결 → iPad에 "이 컴퓨터를 신뢰하시겠습니까?" → **신뢰**.
2. Xcode 위쪽 가운데 기기 선택 메뉴에서 내 **iPad** 선택. (처음엔 "준비 중"이 몇 분 걸릴 수 있습니다.)
3. iPad **설정 → 개인정보 보호 및 보안 → 개발자 모드** 켜기 → 재시동 → 켜기 확인. (메뉴가 안 보이면 ⑦을 한 번 실행한 뒤 다시 보세요.)

**⑦ 실행** — Xcode 왼쪽 위 **▶︎** (또는 ⌘R). 처음 한 번은 iPad에서 실행이 막히는데, **설정 → 일반 → VPN 및 기기 관리 → 내 Apple ID → 신뢰** 후 다시 ▶︎.

**⑧ 7일 뒤** — 무료 서명은 7일 후 만료되어 앱이 열리지 않습니다(문서·앱은 그대로). iPad를 연결하고 Xcode에서 ▶︎ 만 다시 누르면 됩니다. 코드가 바뀌었으면 먼저 `git pull` 하세요.

## 사용법

### Claude 앱(iPhone/iPad)에서 받은 한글 파일 열기
1. Claude가 만든 `.hwp`/`.hwpx` 파일을 누릅니다.
2. **공유** 버튼 → 앱 목록에서 **한글 뷰어** 선택.
   목록에 없으면 **"파일에 저장"** 후, 한글 뷰어 앱을 열어 파일 탐색기에서 선택합니다.

### Mac (claude.ai 웹 / Claude 데스크톱 앱)
파일을 내려받은 뒤 더블클릭하거나 앱 창으로 끌어다 놓습니다.

### 보기 기능
- 상단 **쪽 보기 / 읽기 모드** — 휴대폰에서는 읽기 모드가 글씨가 커서 읽기 편합니다.
- **⋯ 메뉴** → PDF로 저장, 인쇄
- 두 손가락으로 확대/축소, 길게 눌러 텍스트 복사
