# 설치 가이드

이 저장소에 코드를 올리면(push) GitHub Actions가 Mac 서버에서 자동으로 앱을 빌드합니다.
**Mac이 없어도** 빌드 결과물을 내려받아 설치할 수 있습니다.

## 0. 빌드 결과물 내려받기

1. GitHub 저장소 → **Actions** 탭 → 가장 최근의 초록색 ✓ **Build** 실행을 엽니다.
2. 아래쪽 **Artifacts** 에서 `HWPViewer-builds` 를 내려받아 압축을 풉니다.
   - `HWPViewer-macOS.zip` — Mac용 앱
   - `HWPViewer-unsigned.ipa` — iPhone/iPad용 (서명 전 파일)

---

## 1. Mac에 설치 (무료)

1. `HWPViewer-macOS.zip` 압축을 풀고 `HWPViewer.app` 을 **응용 프로그램** 폴더로 옮깁니다.
2. 처음 실행하면 "확인되지 않은 개발자" 경고가 뜹니다 (Apple 유료 인증서로 서명하지 않았기 때문).
   - **시스템 설정 → 개인정보 보호 및 보안** 맨 아래 **"그래도 열기"** 를 누릅니다.
   - 또는 터미널에서 한 번: `xattr -cr /Applications/HWPViewer.app`
3. `.hwp` 파일을 우클릭 → **다음으로 열기 → HWPViewer** → (항상 이 앱으로 열려면) **정보 가져오기 → 다음으로 열기 → 모두 변경**.

## 2. iPhone / iPad에 설치

### 방법 A — 무료 Apple ID로 사이드로딩 (Windows PC 또는 Mac 필요)

1. PC에 [Sideloadly](https://sideloadly.io) (또는 [AltStore](https://altstore.io))를 설치합니다.
2. iPhone을 USB로 연결 → Sideloadly에 `HWPViewer-unsigned.ipa` 를 끌어다 놓고 Apple ID로 로그인 → **Start**.
3. iPhone에서 **설정 → 개인정보 보호 및 보안 → 개발자 모드** 켜기 (iOS 16 이상, 재시동 필요),
   **설정 → 일반 → VPN 및 기기 관리** 에서 내 Apple ID 인증서를 **신뢰**.
4. 무료 Apple ID 서명은 **7일마다 다시 설치**해야 합니다 (AltStore는 자동 갱신 가능).

### 방법 B — Apple Developer Program (연 $99) + TestFlight

1년간 유효한 설치, 가족·동료 배포(최대 1만 명)까지 가능합니다.
1. [developer.apple.com](https://developer.apple.com/programs/) 가입.
2. App Store Connect에서 앱 등록 (번들 ID: `com.hyroot2.HWPViewer`, 원하면 `project.yml` 에서 변경).
3. Mac이 있으면 Xcode에서 **Product → Archive → Distribute App → TestFlight**.
   Mac이 없으면 App Store Connect API 키를 저장소 Secrets에 넣어 GitHub Actions로 업로드하도록 워크플로를 추가할 수 있습니다.
4. iPhone에서 **TestFlight** 앱으로 설치.

### 방법 C — Mac + Xcode가 있을 때 (무료, 7일)

```sh
brew install xcodegen
xcodegen generate
open HWPViewer.xcodeproj
```
Xcode → 타깃 **HWPViewer → Signing & Capabilities → Team** 에 내 Apple ID 선택 → iPhone 연결 → ▶︎ 실행.

## 사용법

### Claude 앱(iPhone/iPad)에서 받은 한글 파일 열기
1. Claude가 만든 `.hwp`/`.hwpx` 파일을 누릅니다.
2. **공유** 버튼 → 앱 목록에서 **한글 뷰어** 선택.
   목록에 없으면 **"파일에 저장"** 후, 한글 뷰어 앱을 열어 파일 탐색기에서 선택합니다.

### Mac (claude.ai 웹 / Claude 데스크톱 앱)
파일을 내려받은 뒤 더블클릭하거나 앱 창으로 끌어다 놓습니다.

### 보기 기능
- 상단 **쪽 보기 / 읽기 모드** — 휴대폰에서는 읽기 모드가 글씨가 커서 읽기 편합니다.
- **⋯ 메뉴** → PDF로 저장, 인쇄
- 두 손가락으로 확대/축소, 길게 눌러 텍스트 복사
